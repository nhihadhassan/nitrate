# Movie Club terminology

Use these terms in member-facing screens, notifications and email. Database fields and server types may keep their existing names.

| Use | Meaning | Avoid in member copy |
| --- | --- | --- |
| Movie Ideas | Movies saved for a future round | Shared Queue, queue suggestion |
| Choose the next movie | Start the current selection process | Start a round |
| Pick your movie | Put a movie into the current selection | Nominate, submit |
| Your pick | The movie a member chose for this round | Your nomination, your submission |
| Movies picked | The current set of choices | Nominations, submissions |
| Vote | Choose between the current picks | Decide phase |
| Wheel | Randomly choose between the current picks | Selection mechanism |
| Next movie | The chosen winner | Winner nomination |
| Movie night | The scheduled group watch | Screening, unless administrative precision is required |
| Mark it watched | Confirm the night happened, which opens ratings | Complete the screening, mark complete |
| Invite link | The event page the club gathers on, outside Nitrate | Partiful link, or any other brand name |
| Watch link | Where the film itself is streamed, called or ticketed | — |

The core distinction is: **Movie Ideas are for later. Your pick is for this round.**

A second one, for a booked night: **an invite link is where people gather, a
watch link is where the film plays.** A club that meets in a living room has
one and not the other; a club that meets on a call may use the same URL twice.
